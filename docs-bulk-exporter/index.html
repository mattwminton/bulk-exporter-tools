Docs Bulk Exporter (works with ClickUp)

A Chrome extension that exports a whole ClickUp Workspace, Space, Folder or List of Docs into one ZIP of Markdown and/or Word (.docx). It keeps the folder hierarchy, saves images offline and keeps links between pages working.

  • Free: the first 3 Docs of each export, so you can check the output on your own content.
  • Workspace ($39 one-time): unlimited Docs per export on 1 ClickUp Workspace.
  • Agency ($79 one-time): unlimited Docs per export on up to 10 ClickUp Workspaces.

One-time payment, no subscription. Secure checkout by Stripe via ExtensionPay. Full refund on request within 14 days of purchase.

Private by design. It uses the official ClickUp API with your own personal token. Your Docs go straight from ClickUp to your computer, and we never receive your token or your content. Read the privacy policy.
